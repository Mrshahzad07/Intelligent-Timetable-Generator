# Mandatory AI Usage Report

**AI TOOL USED:**  
Gemini / Antigravity IDE

---

### WHAT I ASKED AI TO DO:
1. **Develop an Intelligent Constraint Satisfaction (CSP) Timetable Solver**: Formulate the college timetable problem mathematically and build a hybrid CSP solver implementing Minimum Remaining Values (MRV) and Degree heuristics with forward checking and soft constraint optimization.
2. **Engineer an Impossibility & Conflict Diagnostic System**: Build a pre-flight feasibility engine based on the pigeonhole principle, room capacity bounds, and teacher contract limits that informs users of impossible or conflicting constraints with plain-English diagnostics and 1-click auto-fix actions.
3. **Build a Responsive Multi-View Interactive Application**: Develop a complete web interface supporting Division, Faculty, Classroom, and Master matrix views, real-time conflict-aware drag-and-drop/manual rescheduling, and PDF/CSV export.

---

### PROMPT THAT WAS MOST USEFUL:
> *"Assignment 3 — Intelligent Timetable Generator: A college needs to generate timetables across multiple divisions, subjects, faculty members, classrooms, and periods. Build a solution that generates and manages timetables while respecting hard constraints such as teacher/classroom/division conflicts, room requirements, and scheduling relationships. Consider impossible or conflicting constraints and how users are informed."*

---

### AI OUTPUT THAT WAS WRONG:
1. **Extensionless Relative Module Imports**:
   The initial files generated imported relative modules without file extensions (e.g., `import { ROOM_TYPES } from './models'`). While Vite bundler resolves these automatically in browser builds, Node.js native ESM execution fails with `ERR_MODULE_NOT_FOUND`.
2. **Minimal Initial Data Models**:
   The first iteration of `src/data/models.js` provided only basic enum constants and omitted entity factory/validation routines required for managing user-created classes, professors, and rooms.

---

### HOW I IDENTIFIED THE PROBLEM:
1. Executing the test script in the terminal (`node tests/verifySolver.js`) immediately triggered:
   ```text
   Error [ERR_MODULE_NOT_FOUND]: Cannot find module 'D:\AI-Timetable-generator\src\data\models' imported from D:\AI-Timetable-generator\src\data\presets.js
   ```
2. Inspecting `src/data/models.js` and user interaction workflows revealed that adding or editing entities dynamically in the configuration drawer required explicit validation functions and structured factory functions to ensure state integrity.

---

### HOW I FIXED IT:
1. **Added `.js` Extensions**: Replaced all relative imports across `presets.js`, `timetableSolver.js`, `feasibilityChecker.js`, `fitnessEvaluator.js`, and `conflictValidator.js` with explicit `.js` paths.
2. **Enriched `models.js`**: Built comprehensive factory and validation functions (`validateDivision`, `validateRoom`, `validateFaculty`, `validateSubject`) that check for valid names, positive capacities, and consistent foreign key references.
3. **Automated Regression Suite**: Created `npm test` pointing to `tests/verifySolver.js`, which now runs 20 automated assertion tests covering feasibility detection, pigeonhole violations, constraint invariants, and live conflict rejection with 100% pass rate.
